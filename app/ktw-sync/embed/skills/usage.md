# ktw-sync — Usage Guide

ktw-sync synchronizes files between local storage and cloud providers (OneDrive, SharePoint, S3, etc.) via rclone.

## Getting Started

```bash
# Check configuration
ktw-sync config check

# List available skills
ktw-sync skills list
```

## Companion Programs

- **rclone** — cloud storage synchronization engine
