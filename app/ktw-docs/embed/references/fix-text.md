# Fix Text

Clean up broken or malformatted text while preserving all original content.

## Purpose

Restore proper formatting to text that has been mangled by copy-paste errors, OCR artifacts, encoding issues, or other formatting problems.

## Scope

- **Input**: text with formatting problems (broken line breaks, missing punctuation, broken paragraphs, OCR artifacts, etc.).
- **Output**: properly formatted text applied directly in place.

## Process

### Step 1 — Read and understand

Read the entire text to understand its structure, intended formatting, and content.

### Step 2 — Fix formatting

Apply the following corrections:

- Remove strange or misplaced line breaks that disrupt the flow.
- Add capitalization where missing.
- Add punctuation where missing.
- Restore proper paragraph breaks.
- Fix any other formatting issues.

**Do NOT change any content or spelling.**

### Step 3 — Output

Apply the full, properly-formatted text directly to the document in place. Nothing else.
