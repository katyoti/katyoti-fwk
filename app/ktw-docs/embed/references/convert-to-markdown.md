# Convert to Markdown

Reference for converting any content to clean Markdown while preserving it completely and exactly.

---

## Purpose

Convert any content to clean Markdown format while preserving the complete original text. Separates actual content from surrounding noise (ads, comments, navigation). No truncation, no alterations, no placeholders.

## Scope

Input: any content (HTML, raw text, web page extract, document, etc.).

## Process

### Step 1 -- Identify the content

Read through the input to determine its structure. Separate the original content from surrounding noise (ads, comments, navigation, unrelated text).

### Step 2 -- Convert to Markdown

Replicate the identified content as Markdown, preserving:

- All original wording exactly as written
- All original punctuation exactly as it is
- All original links
- All original quotes and code blocks
- All formatting structure (headings, lists, emphasis)

### Step 3 -- Verify completeness

Check the output against the original content to ensure nothing has been truncated or altered.

## Output Format

Clean Markdown replicating the complete original content with proper formatting (headings, lists, emphasis, links, code blocks, quotes).

## Constraints

- Do NOT abridge, truncate, or alter the original content in any way.
- Do NOT insert placeholders such as "content continues below" or similar.
- Output the COMPLETE original content in Markdown -- nothing less, nothing more.
- Preserve all original wording, punctuation, links, quotes, and code blocks exactly.
- Separate content from noise (ads, comments, navigation) but keep all actual content.
