# ktw-notify — Usage Guide

ktw-notify sends notifications via multiple channels (email, Slack, Teams, desktop) and provides text-to-speech.

## Getting Started

```bash
# Check configuration
ktw-notify config check

# List available skills
ktw-notify skills list
```
