# ktw-kb — Usage Guide

ktw-kb manages knowledge bases with document indexing, semantic search, and retrieval-augmented generation (RAG).

## Getting Started

```bash
# Check configuration
ktw-kb config check

# List available skills
ktw-kb skills list
```
