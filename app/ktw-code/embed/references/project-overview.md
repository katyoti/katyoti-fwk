# Project Overview Explanation

## Purpose

Explain what this project is, what it does, how it's organized, and how to run it.

## Scope

Reads: README, package manifests, entry points, top-level directory structure, scripts, Makefile/Dockerfile if present.

## Process

### 1. Identity

- What is this project? (application, library, service, CLI tool, plugin, monorepo)
- What problem does it solve?
- Who is the target audience? (developers, end-users, ops, internal team)

### 2. Structure

- Map the top-level directory layout with purpose of each folder
- Identify entry points (main files, index files, CLI entry, server start)
- Identify test directories and their structure
- Identify build output directories

### 3. How to Run

- Installation steps (from package manifest or README)
- Build commands
- Run commands (dev mode, production mode)
- Test commands
- Environment prerequisites (runtime versions, system dependencies)

### 4. Project Lifecycle

- How is the project versioned?
- How are releases done? (tags, changelog, CI/CD)
- Is there a contribution guide?
